# CareDesk hospital system demo
Clickable demo of a hospital digital system for a private Nigerian hospital: patient records with forgiving search, registration with consent, vitals and consultation notes, allergy warnings, appointments and queue, laboratory, pharmacy stock and expiry, automatic billing, online payment checkout (simulated), WhatsApp notifications, audit log, offline mode, and a patient-facing website.

All data is made up and stored only in the visitor's browser. No real payments. Add `?h=Hospital%20Name` to the URL to show a hospital's name.
